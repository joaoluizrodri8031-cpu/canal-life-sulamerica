# Canal Life — SulAmérica Saúde para Médicos

Landing page estática (HTML + imagens) para campanhas na Meta.
Os botões abrem um mini formulário e redirecionam para o WhatsApp da Canal Life.

- `index.html` — página completa (CSS e JS embutidos)
- `img/` — imagens (fotos de banco gratuito; trocar a do hospital pelo material oficial)
